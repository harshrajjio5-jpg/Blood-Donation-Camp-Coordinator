# Blood Donation Camp Coordinator

## About the Project
Blood Donation Camp Coordinator is a simple and responsive website developed to spread awareness about blood donation. It provides information about upcoming blood donation camps, donor eligibility criteria, and a donor registration form.

## Features
- Simple and user-friendly interface
- Information about blood donation
- Upcoming blood donation camps
- Donor eligibility criteria
- Interactive donor registration form
- Age validation during registration
- Responsive website design

## Technologies Used
- HTML – For website structure
- CSS – For styling and layout
- JavaScript – For interactivity and form validation

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in your browser.

## Project Structure
- index.html – Main webpage
- style.css – Website styling
- script.js – JavaScript functionality
