# 🩸 Blood Donation Camp Coordinator

## About the Project

Blood Donation Camp Coordinator is a responsive website developed to spread awareness about blood donation and provide information about upcoming blood donation camps.

The website allows users to explore different donation camps, check basic donor eligibility criteria, select a camp, choose an appointment time slot, and submit their registration details.

## Features

- User-friendly and responsive website design.
- Information about blood donation.
- Upcoming blood donation camps with dates and timings.
- Camp location details.
- Donor eligibility information.
- Donor registration form.
- Blood group selection.
- First-time and regular donor options.
- Automatic display of selected camp details.
- Appointment time slot selection.
- JavaScript-based form validation.
- Registration confirmation message.

## Technologies Used

- **HTML:** Used to create the structure of the website.
- **CSS:** Used for styling, layout, colors, and responsive design.
- **JavaScript:** Used for form validation, camp selection, displaying camp details, and appointment time selection.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file in your browser.
4. Explore the different sections and test the registration form.
