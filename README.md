## 📖 About the Project

**Blood Donation Camp Coordinator** is a frontend web development project created using HTML, CSS, and JavaScript.

The main purpose of this project is to create an informative platform where users can learn about blood donation, explore upcoming blood donation camps, understand general donor eligibility information, and select a preferred camp and appointment time slot.

The website also includes a dedicated Government Resources section that connects users to official e-RaktKosh resources provided by the Ministry of Health and Family Welfare, Government of India.

The project focuses on creating a simple, accessible and user-friendly experience while demonstrating the practical use of frontend web development technologies.

---

## 🎯 Project Objectives

- Promote awareness about the importance of blood donation.
- Provide information about upcoming blood donation camps.
- Display camp dates, timings and locations.
- Provide general donor eligibility information.
- Create an interactive donor registration form.
- Allow users to select their preferred camp and time slot.
- Connect users with official government blood donation resources.
- Develop a responsive and user-friendly website.

## ✨ Features

### 1. 🏠 Home Page
- Attractive landing page.
- Blood donation awareness message.
- Simple navigation menu.
- Quick access to the registration section.

### 2. ❤️ About Blood Donation
- Introduction to blood donation.
- Information about its importance.
- Encourages people to participate in donation activities.

### 3. 📅 Upcoming Blood Donation Camps
- Displays different sample blood donation camps.
- Shows camp dates and timings.
- Displays camp locations.
- Provides information about different donation events.

### 4. 📝 Donor Registration Form

Users can enter their basic details through an interactive registration form.

The form includes:

- Full name.
- Age.
- Blood group selection.
- Donor type (First-time or Regular).
- Phone number.
- Donation camp selection.
- Preferred appointment time slot.

### 5. ⏰ Camp and Appointment Selection

- Users can select a preferred donation camp.
- Camp date, timing and location are displayed automatically.
- Appointment time slots change according to the selected camp.
- Selected appointment information is displayed after form submission.

### 6. 🏥 Donor Eligibility Information

- Displays general donor eligibility information.
- Provides basic age-related guidance.
- Explains that final eligibility depends on medical screening.

### 7. 🌐 Official Government Resources

A dedicated section provides links to official resources so users can explore authentic blood donation information.

## ⚙️ How the Website Works

### Donor Registration Process

1. The user opens the website.
2. Navigates to the donor registration section.
3. Enters their name and age.
4. Selects their blood group.
5. Chooses their donor type.
6. Enters their phone number.
7. Selects a preferred donation camp.
8. The website automatically displays the camp date, timing and location.
9. The user selects an appointment time slot.
10. JavaScript validates the entered information.
11. A registration confirmation message is displayed.

## ⚠️ Disclaimer

This project is developed for educational purposes as a frontend web development project.

The blood donation camp names, dates, timings, locations and appointment slots displayed on the website are sample information used for demonstration.

The website is not an official government service. For verified blood availability, donation camps and medical eligibility information, users should consult official government resources and qualified medical professionals.
